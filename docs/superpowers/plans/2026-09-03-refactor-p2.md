# Refactor Phase 2 Implementation Plan (memory safety & correctness)

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development or superpowers:executing-plans. Steps use checkbox syntax.

**Goal:** Fix the three P0 defects and the 14 P1 correctness items from
`docs/refactor-audit-2026-09-03.md` §1-§2, one commit each, with the audit's
exact fix designs. This plan references the audit for per-item detail
(file:line + fix direction are there); here we fix the execution order,
the new code that needs designing, and the gates.

**Architecture / workflow / constraints:** identical to the P0-P1 plan
(`docs/superpowers/plans/2026-09-03-refactor-p0-p1.md` Global Constraints —
NAS ssh workflow, pkill safety, commit prefixes `refactor(p2):`, matrix gate).

## Task order (one commit each, risk-ascending)

1. **P0-1 create_surfaces fail path** — v4l2stateless.c `fail:` label.
   Track `int created = i;` when the loop breaks; cleanup loop runs
   `for (j = 0; j < created; j++)` UNDER the lock (move unlock after), and
   use a bounded push: add `surface_id_push(dd, id)` inline helper in the
   header next to `v4l2sl_cap_pool_push` (same bounded/dup-free shape,
   limit `V4L2SL_MAX_SURFACES`), use it in both create-fail and normal
   destroy paths.
2. **P0-2 terminate teardown** — extract `destroy_surface_locked(dd, s)`:
   closes memfd (surf->dma_buf_fd), frees cpu_ptr, destroys gbm bo via
   `v4l2sl_gbm_surface_destroy`, frees the struct, clears the table slot.
   terminate: under g_v4l2sl_lock, walk contexts (existing code), then walk
   `surfaces[]` calling destroy_surface_locked, then free orphan_buffers
   (`munmap` when `b->mmapped`, else `free(b->data)`; free node), then free
   configs list. Unit gate: `tests/va_leak_client.c` under the ASan build
   drops from 11 MB/17 allocs to (approximately) zero driver-attributed
   leaks. Add a `va_leak_client` run to the phase gate.
3. **P0-3 VPP clamp** — vpp.c right after reading `pipe->output_region`:
   `if (pipe->output_region) { dw = min(dw, dst->width); dh = min(dh, dst->height); }`
   (and clamp surface_region against src the same way). Static-min helper
   or plain ternaries — match file style.
4. **C4 grow_memfd never shrinks** — device.c `v4l2sl_surface_grow_memfd`:
   add `uint32_t memfd_size;` to the surface struct; if `s->memfd_size >= size`
   return 0; ftruncate only upward; update `memfd_size` on success. Initialize
   in `v4l2sl_surface_alloc_export_fd` (which ftruncates the first size).
5. **C2 lock coverage** — v4l2stateless.c: wrap the config-list walk in
   `vaQueryConfigAttributes` and the surface-attribute walk in
   `vaQuerySurfaceAttributes` with `g_v4l2sl_lock` (lock/unlock around the
   lookup + copy-out, matching the file's other readers).
6. **C3 create_context early return** — `vaCreateContext`: if config lookup
   fails, `return VA_STATUS_ERROR_INVALID_CONFIG` before opening any device;
   and `strdup` the device_path into the context (free on context destroy)
   so `vaDestroyConfig` cannot dangle it.
7. **C1 destroy_surfaces capture slot return** — in `v4l2sl_destroy_surfaces`
   (under the lock): if `s->buf_index >= 0`, find the owning context via the
   existing `context_for_surface` helper and `v4l2sl_cap_pool_push`; if the
   surface is any context's `current_surface`, NULL that pointer. Remove the
   surface id from `render_targets` arrays of contexts that list it (set to
   VA_INVALID_ID).
8. **C10 poll EINTR retry** — device.c poll sites + vpp.c poll: wrap in
   `do { r = poll(...); } while (r < 0 && errno == EINTR);`.
9. **C9 DQBUF error flag** — device.c dequeue path: when
   `buf.flags & V4L2_BUF_FLAG_ERROR`, log (debug-gated), return the buffer
   via pool push and return -2 from the dequeue helper; caller marks the
   surface `VASurfaceSkipped` and returns SUCCESS from vaEndPicture
   (per VA-API a failed frame is reported via vaQuerySurfaceStatus, not an
   entrypoint error — do NOT fail the vaEndPicture call itself, Chrome's
   failure cache makes that dangerous).
10. **C11 slice arrays to 256** — h264.c + hevc.c: raise the slice_datas
    arrays to 256 (matching pending_buffers) and error loudly when
    exceeded (return VA_STATUS_ERROR_DECODING_ERROR after fprintf).
11. **C7 get_image stride** — record `uint32_t pitch;` in
    `struct v4l2sl_buffer` at vaCreateImage time (like `fourcc`);
    vaGetImage converters write with `ib->pitch`, not the recomputed
    dst_stride.
12. **C8 putImage fourcc/pitch** — vaPutImage: require
    `ib->fourcc == VA_FOURCC_NV12` (else VA_STATUS_ERROR_UNSUPPORTED_RT_FORMAT,
    debug-gated fprintf), and read source rows at `ib->pitch`.
13. **C5 HEVC IQ matrix** — hevc.c: collect `VAIQMatrixBufferType` into a
    `const struct VAQMatrixBufferHEVC *qm`; translate into
    `v4l2_ctrl_hevc_scaling_matrix` (4x4/8x8 lists + DC values); keep
    memset-16 only when absent (field-wise init, not whole-struct memset).
14. **C6 MPEG-2 chroma fallback** — mpeg2.c `v4l2sl_mpeg2_fill_quant`:
    chroma matrices fall back to the luma matrices (per H.262 6.3.7);
    update `tests/test_vp8_mpeg2_fill.c` expectations
    (`fill_quant(&q, NULL)` → chroma intra == mpeg2_default_intra,
    chroma non_intra == 16).
15. **C12 AV1 film grain update_grain** — av1.c film-grain mapping: add
    `if (fg->film_grain_info_fields.bits.update_grain) flags |= V4L2_AV1_FILM_GRAIN_FLAG_UPDATE_GRAIN;`
16. **C13 AV1 fabricated flags** — av1.c: delete the block that force-sets
    REF_FRAME_MVS/WARPED_MOTION from enable_order_hint (keep the true
    per-field mapping above it); drop the SEPARATE_UV_DELTA_Q inference,
    map the real sequence bit (VA exposes it in seq_info_fields).
17. **C14 format.c converter scratch** — replace the 4096-sample stack
    arrays with one shared heap scratch (allocate on first use, cap at the
    driver's real max width; fail loudly past it instead of clamping).
    This is the largest item; if it balloons, split into its own commit
    with the matrix as its only gate.
