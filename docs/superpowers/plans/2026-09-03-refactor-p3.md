3. **xioctl hoisted** — device.c's static xioctl becomes non-static `v4l2sl_xioctl` (decl in header); delete vpp.c and jpeg.c private copies.

6. **attribute tables合一** — one static table (5 config attribs) used by both query paths; MaxPictureWidth/Height = 4096 everywhere (rkvdec real limit; matrix h264_4k=3840 still fits).

9. **PRIME descriptor filler merge** — extract `v4l2sl_fill_prime_layers(desc, fd, w, h, pitch, fourcc, flags)`; device.c fill_prime + gbm.c fill_prime_gbm both call it.
10. **AV1 heuristics sub-struct** — 7 ctx fields → `struct { ... } av1;` + mechanical member renames; also migrate test_export_recapture's two old tests onto recap_env.
11. **probe scanner merge** — scan_decoder_paths_ex and scan_all_uncached share one node-walk core (accept criteria unified to `nout>0 || ncap>0`); dead-enum V4L2SL_REQAPI_UNKNOWN removed or actually used.
