# Refactor Phase 4 Implementation Plan (hot-path performance)

> Same workflow/constraints as P0-P1 plan. One measurable commit per item,
> `refactor(p4):` prefix, `docs/perf-baseline-2026-09.md` is the anchor
> (18.7 ioctl/frame, ~2 mmap+munmap/frame, 2.9 close/frame @ 1080p30).
> Order = benefit/risk; any live regression reverts that item alone.
> NOTE: P3 clusters 7-11 (Annex-B helper, collection helper, descriptor
> merge, AV1 sub-struct, probe merge) deferred until after P4 — they touch
> the same codec functions and pure code-motion is safer on the settled
> post-P4 tree.

## Items

1. **Persistent request fd + MEDIA_REQUEST_IOC_REINIT**
   - begin_picture: drop per-picture close+MEDIA_REQUEST_ALLOC; alloc only
     when request_fd < 0.
   - decode_submit tail: replace close(request_fd) with
     `xioctl(request_fd, MEDIA_REQUEST_IOC_REINIT)` (guarded: on EINVAL fall
     back to the old close+alloc).
   - release_context_device closes it.
   - −2 syscalls/frame.
2. **SPS/sequence controls cached, resubmitted on change**
   - h264 global SPS, hevc SPS, av1 sequence, mpeg2 sequence: keep a
     shadow copy + valid flag in ctx (scratch buffer ~sizeof(ctrl)); memcmp;
     skip the global ioctl when unchanged. First frame always submits.
3. **Request controls batched**
   - h264/hevc: build one v4l2_ext_control[4] (SPS, PPS, decode_params,
     scaling_matrix / HEVC equivalents) → single S_EXT_CTRLS.
   - vp8 already single-control; mpeg2 already batches (model).
   - −3 syscalls/frame.
4. **Output-plane lengths memoized**
   - v4l2sl_queue_output: cache planes[0].length per index in
     ctx->output_buf_len[] on first QUERYBUF; skip the ioctl after.
   - −1 syscall/frame.
5. **cpu_ptr lazy allocation**
   - create_surfaces stops calloc'ing; allocate in the first CPU writer
     (put_image, VPP dst, upload path) via `v4l2sl_surface_ensure_cpu()`.
   - Memory win (60-240MB per pool), no syscall change.
6. **Persistent memfd mapping**
   - pull_capture memfd path + ensure_memfd + derive/get_image: keep one
     mmap per surface (map cached in surface struct, grow-only remap).
   - −2 mmap/munmap per frame on readback clients.
7. **VPP/JPEG persistent queue state** (ffmpeg-path win, ~18→~6 ioctls)
8. **Image stride 64-byte alignment** (cheap NEON alignment win)
