- Commit message prefix: `refactor(p0):` / `refactor(p1):` on branch `refactor/audit-2026-09`.
- SSH target: `liyifan@192.168.1.21` (root refused). sudo via `echo liyifan | sudo -S <cmd>` — NEVER inside a heredoc.
- Kill Chrome only by exact argv prefix with split string: `pkill -f '^/opt/google/chrome/chr''ome --render-node'`. NEVER `pkill -f chrome`.
- Chrome must be restarted after any driver .so change (Chrome caches VA-API failure per session). Relaunch: `nohup google-chrome-stable --user-data-dir=$HOME/.config/gc-dbg --remote-debugging-port=9222 --restore-last-session >/tmp/chrome-relaunch.log 2>&1 &` (`google-chrome-stable` IS the vaapi wrapper at /usr/local/bin).
- Commit messages with apostrophes: write message to a local file, `scp` to NAS `/tmp/msg.txt`, then `git commit -F /tmp/msg.txt`.
- NAS push (only at phase end): retry loop `for i in 1 2 3 4 5; do git push -u origin refactor/audit-2026-09 && break; sleep 25; done` (GnuTLS intermittent failures are known).
- Build: `cd ~/vaapi-v4l2-bridge && ninja -C builddir`. If ninja misses stale objects: `touch src/<file> && ninja -C builddir`.
- Full driver install: `echo liyifan | sudo -S install -m 0755 builddir/v4l2stateless_drv_video.so /usr/lib/aarch64-linux-gnu/dri/`.

```bash
#!/bin/bash
# Live Chrome smoke for the bridge driver: hardware decoder + visible picture.
# Requires: chrome already running via the google-chrome-vaapi wrapper with
# --remote-debugging-port=9222 and a live video tab playing.
# Exit 0 = all three checks pass.
set -u
ROOT=$(cd "$(dirname "$0")/.." && pwd)
export PATH="$HOME/.nvm/versions/node/v24.16.0/bin:$PATH"
fail=0

out=$(node "$ROOT/scripts/chrome_mi.js") || fail=1
echo "$out"
echo "$out" | grep -q "VaapiVideoDecoder" || { echo "SMOKE_FAIL decoder"; fail=1; }
echo "$out" | grep -qi "eglCreateImage.*error" && { echo "SMOKE_FAIL egl"; fail=1; }

br=$(node "$ROOT/scripts/chrome_canvas.js") || fail=1
echo "$br"
avg=$(echo "$br" | grep -oE "avg [0-9]+" | grep -oE "[0-9]+" | head -1)
[ -n "$avg" ] && [ "$avg" -ge 50 ] || { echo "SMOKE_FAIL canvas avg=$avg"; fail=1; }

[ "$fail" -eq 0 ] && echo "CHROME_SMOKE_PASS" || echo "CHROME_SMOKE_FAIL"
exit $fail
```

(If chrome_canvas.js prints the average in a different format, adjust the grep to match its actual output — the contract is: one line containing `avg <number>`.)
