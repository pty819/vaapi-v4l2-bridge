# v4l2stateless_h264.c

`v4l2sl_h264_translate`：SPS/PPS/DecodeParams/ScalingMatrix →
对应 `v4l2_ctrl_h264_*`，OUTPUT 拷 slice 数据。

## QpBdOffsetY

ffmpeg VA 把 10-bit 的 `QpBdOffsetY`（+12）打进 `pic_init_qp_minus26`。
V4L2 要的是码流裸值。不剥的话 High10 花屏（唯一根因，已修）。
8-bit 这条偏移是 0，无影响。

## DPB

`h264_fill_decode_params` 把 VA 参考 surface id 换成
`v4l2sl_surface_ts()`。内核按 timestamp 找 CAPTURE。

## High422

库存 ffmpeg 不会给 4:2:2 走 VAAPI（pix_fmt 列表 + profile map 双门）。
矩阵用 `tests/va_h264422_client.c`。内核路径可用 GStreamer
`v4l2slh264dec`。NV20 帧尾 colmv 不要拿 GST videoconvert 做位级判据。
